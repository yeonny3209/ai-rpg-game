| 영역 | 내용 |
|---|---|
| 성장 | 레벨 1~10(누적 경험치 표는 BALANCE_P1.md 6장), 직업별 레벨당 능력치 성장, 레벨업마다 스킬 포인트 1개와 체력 성장분만큼 회복 |
| 스킬 | 직업당 3개, 키 Q/E/F. 전사: 돌진·범위 베기·방어 태세 / 마법사: 강타·불꽃 지대·충격파 |
| 스킬 트리 | `T` 화면. 첫 스킬은 처음부터 열려 있고, 나머지 둘은 1포인트로 잠금 해제. 랭크 1→3은 포인트 1개씩, 랭크마다 피해 +20% |
| 적 | 사이버 개(근접), 정찰 드론(원거리, 거리 유지하며 발사), 중장갑 보병(근접 탱커), 프로토타입 메카(보스, 접촉 공격 + 8발 탄막) |
| 웨이브 | 1~4웨이브는 점점 많아지고, 5의 배수 웨이브는 보스 + 개 2마리. 클리어하면 체력 50% 회복 |
| 아이템 | 무기·방어구·장신구, 등급 4단계(일반 60% / 고급 28% / 희귀 10% / 영웅 2%), 웨이브가 높을수록 수치 +10%씩 |
| 드롭 | 개 25%, 드론 30%, 보병 40%, 보스 100%(희귀 이상). 바닥에서 걸어가면 줍고 45초 뒤 사라짐. 가방 16칸 |
| 화면 | `I` 장비·인벤토리(클릭으로 장착·해제), `T` 스킬 트리(클릭 또는 1·2·3), 경험치바·보스 체력바·쿨다운 HUD. 메뉴가 열리면 게임이 멈춰요 |

## 4. 자동 검증 결과 (이 환경의 한계: 화면이 초당 1프레임이라 업데이트를 직접 호출해 확인)
- 계산: 웨이브 구성, 드롭 등급 분포(60.1/27.8/10.2/2.0%), 보스 드롭(항상 희귀 이상), 레벨 경계, 레벨 10 능력치, 스킬 랭크 배율 — 모두 기대값
- 동작: 레벨업, 스킬 해금·랭크 한도, 장비 교체·해제, 가방 가득, 범위 베기 반경, 방어 태세, 드론 거리 유지·발사, 회피로 투사체 무효, 기절, 보스 탄막 8발, 보스 XP·드롭, 불꽃 지대 합계 피해, 충격파 범위
- 화면: 스킬 트리 클릭, 인벤토리 클릭 장착, HUD 확인
- **봇 시뮬레이션**(근처 적 조준·공격·스킬, 장비 자동 장착, 회피는 체력 낮을 때만): 위 수치 적용 후
  - 마법사: 보스 처치 3/3 (약 50초, 레벨 6)
  - 전사: 보스까지 도달하지만 **0/3 처치**(보스 체력 잔여 약 300~900 / 2500에서 사망, 레벨 5)
  - 전사 봇은 보스 옆에 붙어 탄막·접촉 공격을 계속 맞아요. 사람이 거리를 벌리고 회피하면 달라질 수 있어요(미확인)

## 5. 알려진 한계·남은 일
- **전사 난이도 불확실**: 직접 플레이로 확인 필요. 힘들면 방어 태세 반격, 체력 성장 등으로 보강
- 보스 웨이브(5, 10, ...)는 모두 같은 보스. 이후 웨이브 수치 확장은 미구현
- 방어 태세의 "반격"과 장비 강화는 미구현(PLAN 기준 Phase 2 범위 밖이었던 강화 포함)
- 저장 없음(Phase 4). 장비는 새 게임에서 초기화
- 에셋은 모두 임시 도형
- 적끼리 밀어내는 계산이 적 수의 제곱으로 늘어요(적이 많아지면 재검토)
- 자동 테스트 도구는 아직 없음
