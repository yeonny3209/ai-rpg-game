# AI별 할 일 (Phase 1 시작 전 / Phase 1 중)

작성일: 2026-11-22. 역할은 PLAN.md 5장 기준이에요.
- 클로드 코드(지휘자): 설계, 핵심 코드 구현, 결과 정리, 최종 판단
- 코덱스: 코드 검토 (버그, 구조, 테스트 누락)

## D. 호출 규칙 (공통)

1. 검토할 파일만 `review\<작업이름>\` 폴더에 복사해요. 이 폴더는 git에서 제외돼 있어요.
2. 비밀·키·토큰·개인 정보는 넣지 않아요.
3. 호출은 래퍼로만 해요.
   - 코덱스: `tools\call-codex.ps1 -WorkDir review\<작업> -Model gpt-6-luna -Prompt "..."`
   - 안티그래비티: `tools\call-agy.ps1 -WorkDir review\<작업> -Model gemini-3.8-flash-low -Prompt "..."`
4. 한 번에 한 가지만 물어요. 답은 "문제 / 이유 / 제안" 세 줄 형식으로 요청해요.
5. 직원 답은 참고예요. 클로드가 확인한 뒤 반영해요.
6. 60초 제한이 있어서 긴 검토는 파일을 나눠 여러 번 물어요.
7. 모델 거절·한도 오류가 나면 같은 방식으로 반복하지 않고 모델 ID나 한도를 먼저 확인해요.

- 안티그래비티: "이 수치 표를 읽기만 하고, 너무 강하거나 약한 항목을 '문제 / 이유 / 제안' 세 줄씩 최대 5개로 알려 줘."
