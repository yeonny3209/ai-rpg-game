# Phase 1 코드 구조 (v1, 코덱스 검토 반영)

목표: 작은 방에서 WASD로 움직이고 마우스로 조준해 적(사이버 개 1종)과 싸운다. 그래픽은 임시 도형.
v1: 코덱스 검토(A2)를 반영했어요. 구현하면서 바뀔 수 있어요.

## 1. 폴더 구조
```
src/
  main.ts                # 게임 설정, 씬 등록
  config.ts              # 화면 크기, 공통 상수
  scenes/
    BootScene.ts         # 시작 확인 (지금 있음)
    PlayScene.ts         # 작은 방 전투 씬
  entities/
    Player.ts            # 이동, 조준, 공격, 회피, 체력
    Enemy.ts             # 사이버 개 (돌격 AI)
  systems/
    combat.ts            # 피해 계산식 (순수 함수), 피격 처리
    input.ts             # WASD·마우스 입력 모음
  data/
    classes.json         # 직업 수치
    enemies.json         # 적 수치
    skills.json          # 스킬 수치
```

## 2. 핵심 원칙
1. **수치는 JSON에, 로직은 코드에.** 밸런스 조정은 JSON만 고쳐요.
2. **피해 계산은 순수 함수**(`combat.ts`)로 분리해서 화면 없이도 검증할 수 있게 해요.
3. **프레임 독립**: 이동·쿨다운은 `delta` 시간으로 계산해요(모니터 주사율이 달라도 같은 속도).
4. **엔티티는 상태를 스스로 관리**해요(대기, 이동, 공격, 피격, 사망 등).
5. 임시 도형은 한 곳에서 만들어 나중에 이미지로 교체하기 쉽게 해요.
6. 에셋 경로는 `import.meta.env.BASE_URL` 기준으로 불러와요(GitHub Pages 하위 경로 대비, 코덱스 지적).

## 3. 구현 순서와 확인 기준
| 순서 | 내용 | 확인 방법 |
|---|---|---|
| 1 | PlayScene + 플레이어 이동(WASD) | 브라우저에서 도형이 움직이고 대각선 속도가 빠르지 않아요. |
| 2 | 마우스 조준 + 기본 공격(투사체 또는 근접 판정) | 마우스 방향으로 공격이 나가요. |
| 3 | 회피(대시, 무적, 쿨다운) | 회피 중 피격이 무시돼요. |
| 4 | 적 1종 돌격 AI, 체력, 피격, 사망 | 적이 쫓아오고 맞으면 줄어요. |
| 5 | 플레이어 피격·사망·재시작 | 체력이 0이면 재시작돼요. |
| 6 | 직업 선택 2개(수치만 다름) + 스킬 1개씩 | 직업에 따라 수치와 스킬이 달라요. |

각 순서가 끝나면 `npm run build`, 브라우저 확인, 커밋 순으로 해요. 2~4 완료 후 코덱스 검토를 해요.

## 4. 테스트 방법
- 처음에는 **수동 확인 + 피해 계산 함수 단위 테스트**로 시작해요.
- 단위 테스트 도구(Vitest 등) 추가는 `combat.ts`가 생길 때 결정해요(의존성 추가는 승인 후).

## 5. 코덱스 검토 반영 (v0 → v1)
1. **책임 분리**: 엔티티(Player/Enemy)는 상태와 연결만 맡고, 이동·전투·체력 로직은 systems/로 나눠요.
2. **HUD 분리**: PlayScene은 시스템 연결과 생명주기만 맡고, 체력바 등은 별도 UI 모듈(ui/Hud.ts)로 둬요.
3. **데이터 검증**: JSON을 불러올 때 필수 항목·값 범위를 검사하고, 틀리면 명확한 오류를 내요(data/validate.ts).
4. **테스트 확대**: 피해식뿐 아니라 이동 정규화, 회피 무적·쿨다운, 사망 상태 전이도 자동 테스트 후보예요(Vitest 도입은 승인 후).
5. **열린 질문 답**: UI는 별도 모듈 / 충돌은 Phaser 물리 + 단순 투사체만 직접 계산 / 대각선 이동은 입력 정규화 / 상태 머신은 Player·Enemy에 먼저 두고 공통성이 보이면 유틸로 추출.
